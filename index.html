02 / Foundations

Color has a job.

Paper carries the field. Ink carries hierarchy. Signal, hot, acid, and violet are not decoration; each one marks a decision, a state, or a change in temperature.

03 / Type roles

One voice, tuned by role.

Siftion UI carries the whole system. Scale, weight, tracking, and line length create hierarchy without asking a second typeface to perform personality.

04 / Controls

Actions should say what happens next.

The control language is intentionally blunt. Buttons state an outcome, fields leave room for thought, and status is always communicated with language as well as color.

05 / Composition

Compose by role, not by template.

Use the grid as a starting condition. A module can become a dashboard metric, an editorial note, a launch-page callout, or an experiment without losing its underlying logic.

06 / Motion

Move only when something changes.

The system has a small motion vocabulary: enter, shift, reveal, respond. Motion should clarify a state change or direct attention, never ask the interface to perform for its own sake.
