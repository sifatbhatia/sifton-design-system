what comes with a pattern?

the markup in this panel, shared styles, and a small initializer for behaviors that need javascript. native choices and disclosures need no script.

can i use more than one?

yes. give each instance unique ids and radio names. call SiftionUI.init(container) after adding it. existing controls will not bind twice.

what happens without motion?

the same state change, without the travel. no information depends on an animation finishing.
